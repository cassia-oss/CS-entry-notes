# CS Entry Notes

本仓库用于整理我在2025年秋季选修高瓴人工智能学院大一基础课python与人工智能课程的课程笔记、代码练习与问题总结。

## Contents

目前仓库主要包括以下内容：

* **Python Fundamentals**

  * 基本数据类型与控制结构
  * 函数、参数传递与作用域
  * 面向对象编程（Object-Oriented Programming, OOP）
  * 类属性、实例属性、继承与魔法方法

* **NumPy and Data Processing**

  * `ndarray` 的基本操作
  * 索引、切片与维度变换
  * 广播机制（Broadcasting）
  * 常用数学与统计函数
  * 数据类型与内存存储

* **PyTorch Fundamentals**

  * 张量（Tensor）的创建与运算
  * 自动微分（Autograd）
  * 梯度计算与计算图（Computational Graph）
  * `Dataset` 与 `DataLoader`
  * 简单神经网络的构建、训练与测试

* **Machine Learning Basics**

  * 线性回归（Linear Regression）
  * 分类问题与模型评价
  * Accuracy、Precision、Recall 等指标
  * 损失函数（Loss Function）与优化器（Optimizer）

* **Neural Networks and CNN**

  * 全连接神经网络（Fully Connected Neural Network）
  * 卷积层、卷积核与参数量计算
  * AlexNet、ResNet 等经典网络的基本思想
  
## Notes

本仓库是个人学习记录，并非完整或严格的课程教材。部分内容可能随着后续学习继续修正和补充。

The repository documents my transition from a finance background toward computer science, data science and artificial intelligence. It is intended to record not only the final code, but also the reasoning, mistakes and revisions involved in the learning process.
